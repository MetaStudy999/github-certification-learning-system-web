## 원칙

- 자동 검증과 SELF-ATTESTED Evidence를 구분합니다.
- 원문 Evidence 기준은 GCLS 콘텐츠 Repository `001-foundations/150-evidence`입니다.
- Package는 현재 DB 상태에서 재생성 가능한 Snapshot입니다.
- 자동 판정은 `CLEAR_CANDIDATE`까지만 합니다. 실제 시험 합격 또는 자격 상태를 대신 판정하지 않습니다.
