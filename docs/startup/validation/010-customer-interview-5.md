## 4. 사전점검 문안에 넣을 수치

실제 인터뷰 후 아래를 계산한다.

- 인터뷰 인원: `n = `
- 최근 1개월 내 Git 문제 경험: `명 / n명`
- AI를 사용해 해결: `명 / n명`
- 동일 문제 재해결 자신감 평균: `/5`
- Replay·직접훈련 사용 의사(매우+사용해보고 싶다): `명 / n명`
- 월 9,900원 이상 지불 의사: `명 / n명`
- 베타 참여 의향: `명 / n명`

## 5. Q2/Q3/Q3-2 삽입용 문장 틀

> 실제 타깃 사용자 `[n]명`을 인터뷰한 결과, `[x]명`이 최근 한 달 내 Git 문제로 검색·AI·동료 도움을 다시 사용했다고 답했고, 동일 문제를 혼자 다시 해결할 수 있다는 자신감은 평균 `[a]/5`였습니다. `[y]명`은 성공 해결과정을 Replay하고 직접 다시 수행하는 기능을 사용해 볼 의향을 보였으며, `[z]명`은 월 9,900원 이상 지불 가능성을 표시했습니다. 이 결과를 근거로 초기 고객과 가격 가설을 추가 검증하겠습니다.

> 위 문장은 실제 조사 결과와 일치할 때만 사용한다.

## 6. 빠른 실행 원칙

1. 설문 링크를 만드는 데 시간을 쓰지 않아도 된다. 전화·카카오톡·대면으로 5분씩 진행한다.
2. 먼저 기능을 설명하지 말고 최근 Git 문제 경험부터 묻는다.
3. 가격 질문은 마지막에 한다.
4. 긍정 답변을 유도하지 않는다.
5. 실제 응답 원문을 짧게 메모해 두고 숫자만 신청서에 요약한다.
