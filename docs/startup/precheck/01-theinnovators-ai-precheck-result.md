## Q2 · 아이디어를 떠올린 배경 이야기

**1161 / 2000자**

Git을 배우기 위해 온라인 강의를 들어 보았지만, 브랜치·커밋·머지 같은 개념이 실제 작업 화면과 연결되지 않아 이해하기 어려운 부분이 많았습니다. 명령어를 외우는 것과 실제 프로젝트에서 지금 무엇을 해야 하는지 판단하는 것은 전혀 다른 문제라는 점을 체감했습니다.

이 문제를 가장 크게 느낀 것은 코디세이(Codyssey) GitHub 팀프로젝트였습니다. 팀원들과 브랜치를 나누고 변경사항을 합치며 충돌과 오류를 해결하는 과정에서 AI 어시스턴트를 활용했습니다. 현재 상황과 오류 메시지를 질문하면 원인과 해결 방법을 설명해 주어 문제를 하나씩 해결할 수 있었습니다. 이때 글로만 설명하는 것보다 Git Graph처럼 브랜치와 커밋 흐름을 시각적으로 보여주고, 다음에 입력해야 할 명령어와 그 이유까지 함께 안내한다면 입문자가 훨씬 빠르게 이해할 수 있겠다는 생각이 들었습니다.

팀프로젝트를 진행하며 Git은 강의 한 번으로 익숙해지는 도구가 아니라는 점도 알게 되었습니다. 입문자는 현재 브랜치와 작업 상태를 이해하기 어렵고, 검색으로 찾은 명령을 자신의 상황에 그대로 적용하기도 어렵습니다. 경험이 있는 사람도 오랜만에 사용하는 rebase, stash, cherry-pick, reflog 같은 기능이나 낯선 오류를 만나면 다시 검색하게 됩니다.

또한 문제를 한 번 해결해도 시간이 지나면 그 과정을 다시 기억하기 어렵습니다. 해결 작업을 명령 순서, Git Graph 변화, AI 설명과 함께 다시 재생하고 직접 따라 훈련할 수 있다면, 단순히 AI가 대신 해결해 준 경험이 아니라 내가 다시 해낼 수 있는 기술로 전환할 수 있다고 생각했습니다.

내가 Git과 GitHub를 어느 정도 알고 있고 무엇이 부족한지 파악하기 어렵다는 점도 문제였습니다. 실제로 어떤 질문을 했고, 어떤 실습에서 성공·실패했으며, 같은 문제를 도움 없이 다시 해결할 수 있는지가 더 중요한 학습 데이터라고 보았습니다. 이 데이터를 GitHub 자격증의 대분류와 하위 학습 항목에 연결하면 자신의 지식 수준을 수치로 확인하고 부족한 부분을 재학습할 수 있다고 생각했습니다.

이러한 경험을 바탕으로 Git을 사용하는 순간 곁에서 도와주는 코칭 에이전트, 성공 작업 재현 훈련, GitHub 자격증 준비도 대시보드를 하나로 연결하는 실행형 AI Git 코치 아이디어를 구상했습니다.

## Q3-1 · 문제 및 차별성

**1089 / 2000자**

Git 사용자의 핵심 문제는 명령어를 모르는 것이 아니라, 현재 저장소 상태에서 어떤 명령을 안전하게 사용해야 하는지 판단하기 어렵고, 문제를 해결한 뒤에도 그 경험을 반복 훈련하거나 실제 역량으로 축적하기 어렵다는 점입니다.

기존 강의·블로그·공식 문서는 학습에 유용하지만 사용자의 실제 브랜치·커밋·원격 저장소 상태를 반영하기 어렵습니다. 게임형 Git 학습 앱은 반복학습에 강점이 있지만 실제 개발 중 발생한 오류를 맥락에 맞게 진단하고 해결하는 용도와는 차이가 있습니다. 범용 생성형 AI는 질문에 답할 수 있지만 실제 상태, 장기간의 질문·실습·오답·재현 데이터를 하나의 학습체계로 연결하려면 별도 구조가 필요합니다.

본 아이디어는 학습 → 실습 → 문제해결 → 검증 → 복구 → 재현 → 직접훈련 → 역량측정 → 재학습으로 이어지는 흐름을 연결합니다. 사용자가 자연어나 오류 메시지를 입력하면 상태를 먼저 확인하고 원인을 설명한 뒤 단계별 명령을 제시합니다. Git Graph로 브랜치·커밋 흐름을 시각화하고, 위험 명령은 즉시 실행하지 않고 경고·백업·복구 가능 여부를 먼저 안내합니다.

사용자는 프로젝트 보안 수준과 목적에 따라 Local LLM, Cloud API, Hybrid 모드를 선택할 수 있습니다. 비공개 저장소나 민감한 코드는 로컬에서 우선 처리하고, 복잡한 추론이나 교육 콘텐츠 생성은 민감정보를 마스킹한 뒤 클라우드 모델을 사용하도록 설계합니다. 기업은 저장소 유형별 모델 사용정책도 설정할 수 있습니다.

문제가 해결되면 성공 작업을 명령·상태·결과·설명·Git Graph 변화가 포함된 이벤트로 저장합니다. 사용자는 속도를 조절해 다시 재생하거나 같은 문제를 직접 터미널에서 다시 해결할 수 있으며, 오답에는 단계별 힌트를 제공합니다. 질문·실습·오답·재현 결과는 GitHub 자격증별 대분류와 하위 카테고리에 매핑해 준비도와 부족 영역을 보여줍니다.

장기적으로는 성공 히스토리를 AI가 장면·말풍선·자막·음성 설명으로 구성해 교육영상으로 전환합니다. 단순 Git 강의나 AI 챗봇이 아니라 현재 문제 해결부터 안전한 실행, 재현 훈련, 역량 측정, 교육자산화까지 연결하는 실행형 AI Git 코치입니다.
