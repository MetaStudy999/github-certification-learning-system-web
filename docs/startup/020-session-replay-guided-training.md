# AI Git Coach — 성공 작업 재현·따라하기 훈련 기능

> 상태: 모두의창업 MVP 확장 기능 설계
>
> 작업 브랜치: `feature/ai-git-coach-mvp`
>
> 작성일: 2026-09-16

## 1. 기능 목적

사용자가 오늘 Git 작업에서 실제로 문제를 해결하고 성공한 과정을 단순히 잊어버리지 않도록, 해당 과정을 **구조화된 이벤트 로그**로 저장하고 나중에 다시 재생하거나 직접 따라 하며 훈련할 수 있도록 한다.

핵심 목표는 다음 두 가지다.

1. **Replay Mode(재현 모드)**: 성공한 해결 과정을 자동 시뮬레이션으로 다시 보여준다.
2. **Guided Practice Mode(따라하기 훈련 모드)**: 사용자가 같은 과정을 직접 명령어로 입력하고 검증받으며 다시 수행한다.

이 기능은 단순 화면 녹화보다 `Git 상태 + 명령 + 결과 + 설명 + Git Graph 변화`를 함께 저장하는 것을 기본으로 한다.

---

## 2. 핵심 사용자 경험

### A. 오늘의 성공 작업 저장

예시:

```text
문제: push가 되지 않음
↓
git status
↓
git remote -v
↓
git pull --rebase origin main
↓
git push origin main
↓
성공
```

AI Git Coach는 성공 시 다음 데이터를 하나의 `session replay`로 저장한다.

- 문제 설명
- 사용자의 질문
- 당시 브랜치
- Git Graph 상태
- 실행한 명령어 순서
- 각 명령의 실행 결과 요약
- AI 설명
- 위험도
- 성공/실패 여부
- 관련 GitHub 자격증 영역
- 소요 시간

민감한 경로, 토큰, 이메일, 저장소 비밀값, 소스코드 원문은 저장 전 마스킹한다.

---

## 3. Replay Mode — 성공 과정 자동 재현

사용자는 저장된 성공 작업을 선택하고 재생 속도를 조절한다.

### 속도 제어

- `0.5x` : 입문자 학습용 느린 재생
- `1.0x` : 기본 재생
- `1.5x` : 복습
- `2.0x` : 빠른 확인
- Step : 한 단계씩 수동 진행

### 화면 구성

기존 AI Git Coach 3열 화면을 그대로 활용한다.

```text
왼쪽                 가운데                     오른쪽
Git Graph             Terminal                   AI Coach
브랜치 변화           입력 명령 확대             당시 설명
커밋/머지 변화        실행 결과                  왜 이 명령인가
```

재생 중 현재 단계는 강조 표시한다.

예:

```text
STEP 2 / 4

$ git remote -v

원격 저장소가 올바르게 연결되어 있는지 확인합니다.
```

Git Graph는 해당 명령 실행 전/후 상태 변화를 애니메이션 또는 단계 전환으로 보여준다.

---

## 4. Guided Practice Mode — 직접 따라서 재현 훈련

Replay를 본 뒤 사용자가 직접 같은 문제를 해결한다.

### 기본 흐름

```text
문제 상황 제공
↓
사용자가 터미널에 명령 입력
↓
자동 채점
↓
정답이면 다음 단계
오답이면 힌트
↓
최종 해결
↓
복습 결과 저장
```

예시:

```text
[문제]
현재 로컬 main 브랜치가 원격보다 뒤쳐져 있어 push가 거부되었습니다.
어떤 명령부터 확인해야 할까요?

$ _
```

정답:

```bash
git status
```

오답인 경우 AI가 바로 정답을 보여주지 않고 단계별 힌트를 제공한다.

- 1차: "현재 저장소 상태부터 확인해 보세요."
- 2차: "Git의 상태 확인 명령을 떠올려 보세요."
- 3차: `git st...`

사용자가 정답을 입력하면 Git Graph와 Terminal 상태가 다음 단계로 변경된다.

---

## 5. 시뮬레이션 재현은 '영상 녹화'보다 이벤트 기반을 우선

오늘 MVP에서는 실제 화면을 MP4로 녹화하여 저장하는 방식보다 아래 구조를 우선한다.

```text
사용자 행동
↓
Event Log 저장
↓
Replay Engine
↓
Git Graph / Terminal / AI 설명 재구성
```

이 방식의 장점:

- 재생 속도를 자유롭게 변경 가능
- 명령 단위로 일시정지 가능
- 특정 단계부터 다시 시작 가능
- 동일 세션을 훈련 문제로 변환 가능
- 개인정보·소스코드를 마스킹하기 쉬움
- GitHub 자격증 학습 데이터로 재사용 가능

향후 필요하면 Replay를 기반으로 MP4/GIF/WebM 내보내기 기능을 추가한다.

## 7. GitHub 자격증 학습과 연결

성공한 실전 작업을 해당 자격증 영역에 자동 연결한다.

예:

```text
push 문제 해결
├─ GitHub Foundations
│  ├─ Git basics
│  ├─ repositories
│  └─ collaboration
└─ 실전 숙련도 +1
```

또는 GitHub Actions 문제라면:

```text
workflow 오류 해결
└─ GitHub Actions
   ├─ workflow syntax
   ├─ secrets
   └─ reusable workflows
```

대시보드에는 다음을 반영한다.

- 성공 재현 횟수
- 직접 훈련 성공률
- 힌트 없이 해결한 비율
- 평균 해결 시간
- 반복 실패 영역
- 최근 숙련도 변화

준비도는 공식 시험 합격률이 아니라 서비스 내부 학습 준비도 지표로 표시한다.

## 8. 오늘 MVP 범위

시간 제한을 고려해 오늘 반드시 구현할 최소 범위는 다음과 같다.

### MVP-1

- 데모용 성공 세션 1개
- Play / Pause
- `0.5x / 1x / 1.5x / 2x`
- Step Forward / Restart
- Terminal 명령 단계별 출력
- Git Graph 현재 단계 강조
- AI 설명 단계별 표시

### MVP-2

- `따라하기 훈련` 버튼
- 사용자가 명령 직접 입력
- 정답/오답 판정
- 힌트 표시
- 성공 시 완료 화면

### 오늘 제외

- 실제 화면 동영상 자동 녹화
- MP4/WebM 내보내기
- 모든 저장소의 완전 자동 Session Capture
- 위험 명령 실제 자동 실행

이 기능들은 제출 이후 Phase 2로 확장한다.

## 9. 데모 영상에 넣기 좋은 10~15초 장면

```text
[실전 문제 해결 완료]
        ↓
"오늘 해결한 과정을 다시 연습하시겠습니까?"
        ↓
[Replay 1.0x]  [직접 따라하기]
        ↓
Git Graph + Terminal + AI 설명 자동 재현
        ↓
사용자가 직접 git status 입력
        ↓
PASS
```

짧은 장면만으로도 다음 메시지를 전달할 수 있다.

> AI가 답을 대신 주는 것이 아니라, 실제로 해결한 경험을 다시 재현하고 직접 수행하게 하여 사용자의 Git 역량으로 전환한다.

---

## 10. 사업적 의미

이 기능은 AI Git Coach를 단순 문제 해결 도구에서 **경험을 학습자산으로 축적하는 훈련 플랫폼**으로 확장한다.

```text
실전 문제
→ AI 도움
→ 문제 해결
→ 성공 과정 저장
→ Replay
→ 직접 재현 훈련
→ 숙련도 측정
→ 자격증 준비도 반영
→ 부족 영역 재학습
```

핵심 지표 후보:

- 해결 세션 저장률
- Replay 실행률
- Replay 후 직접 훈련 전환율
- 무힌트 재현 성공률
- 재현 훈련 후 동일 오류 재발률 감소
- 7일 재사용률

## 11. 모두의창업 신청서 반영 원칙

이 기능은 아이디어의 확장성과 반복사용 이유를 보여주는 강한 요소이지만, 제출 전 MVP 범위를 지나치게 크게 보이지 않도록 표현한다.

### Q3-1 차별성에 반영할 핵심 문장

> 문제 해결에 그치지 않고, 성공한 Git 작업을 단계별 시뮬레이션으로 다시 재현하고 사용자가 직접 같은 명령을 수행하는 훈련으로 전환하여 실제 해결 경험을 개인의 Git 역량으로 축적합니다.

### Q4-1 사업화 계획에 반영할 핵심 문장

> 초기 MVP에서는 성공한 문제 해결 과정을 명령·상태·설명 이벤트로 저장해 속도 조절 가능한 Replay와 직접 따라하기 훈련으로 재생하는 기능을 검증하고, 이후 실제 작업 세션 자동 수집과 영상 내보내기로 확장합니다.

## 결론

이 기능은 오늘 MVP에서 **이벤트 기반 Replay + 따라하기 훈련**까지만 구현하면 충분하다. 실제 동영상 녹화·내보내기는 후속 기능으로 두는 것이 일정과 안정성 측면에서 적절하다.
