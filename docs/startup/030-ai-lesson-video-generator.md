# AI Git Coach — AI 교육영상 자동 제작 기능

> 상태: 모두의창업 차별화 확장 기능 설계
>
> 작업 브랜치: `feature/ai-git-coach-mvp`
>
> 작성일: 2026-09-16

## 1. 기능 목적

사용자가 해결한 Git 작업 히스토리와 Replay 세션을 기반으로 AI가 교육 목표를 설정하고, 해당 목표에 맞는 교육 시나리오·말풍선·음성 설명·시뮬레이션을 자동 구성하여 영상으로 저장할 수 있도록 한다.

핵심은 단순 화면 녹화가 아니라 다음 구조다.

`실제 작업 히스토리 → 학습 목표 설정 → 장면 구성 → 시뮬레이션 실행 → 설명/말풍선/음성 동기화 → 영상 출력`

이 기능은 ChatGPT 웹 화면을 직접 제어하는 방식보다 OpenAI API를 애플리케이션 내부에서 사용해 구현하는 것을 기본으로 한다.

---

## 2. 핵심 사용자 경험

사용자가 성공한 작업 세션에서 다음을 선택한다.

```text
[교육영상 만들기]

목표:
- 입문자가 push 오류 해결 과정을 이해하도록
- Git Graph에서 branch 변화까지 설명
- 위험 명령은 별도 경고

대상:
- 입문자

길이:
- 60초
- 90초
- 3분

속도:
- 0.5x / 1.0x / 1.5x / 2.0x
```

AI는 작업 히스토리를 분석해 장면 계획을 생성한다.

```text
Scene 1 — 문제 소개
Scene 2 — git status
Scene 3 — Git Graph 변화
Scene 4 — 원격 저장소 확인
Scene 5 — push 재시도
Scene 6 — 성공 확인
Scene 7 — 자격증 학습영역 연결
```

## 3. 화면 구성

기존 3열 AI Git Coach UI를 그대로 활용한다.

```text
왼쪽                    가운데                     오른쪽
Git Graph                Terminal                   AI Coach
현재 branch 강조         실행 명령 확대             말풍선 설명
commit 변화              명령 출력                  핵심 개념
merge/rebase 변화        Step 진행                  주의사항
```

영상 생성 모드에서는 추가로 다음 Overlay를 표시한다.

- 장면 제목
- 현재 Step 번호
- 학습 목표
- 핵심 명령어 확대
- AI 말풍선
- 위험도 경고
- GitHub 자격증 연결 영역
- 자막

## 4. AI Director — 교육 목표에서 장면 계획 생성

AI는 다음 입력을 받는다.

```json
{
  "goal": "입문자가 push 오류 해결 과정을 이해하도록 설명",
  "audience": "beginner",
  "durationSec": 90,
  "sessionId": "session_xxx",
  "certification": "GitHub Foundations"
}
```

출력 예시:

```json
{
  "title": "push가 안 될 때 90초 해결법",
  "learningObjectives": [
    "현재 Git 상태를 먼저 확인한다",
    "원격 저장소 연결을 확인한다",
    "push 전에 필요한 작업을 이해한다"
  ],
  "scenes": [
    {
      "step": 1,
      "type": "terminal",
      "command": "git status",
      "bubble": "먼저 현재 상태를 확인합니다.",
      "narration": "push가 실패했을 때 바로 다른 명령을 실행하지 말고 현재 브랜치와 변경사항부터 확인합니다.",
      "durationSec": 12
    }
  ]
}
```

AI는 사용자의 수준에 따라 설명 깊이와 장면 수를 조절한다.

---

## 5. 음성 설명

장면별 `narration`을 TTS(Text-to-Speech, 음성합성)로 변환한다.

구현 원칙:

- 서버에서 음성 생성
- 한국어/영어 지원
- 장면별 오디오 파일 생성
- 시뮬레이션 타임라인과 동기화
- 사용자가 음성 On/Off 선택 가능

향후에는 음성 스타일, 설명 속도, 초급/전문가 설명 모드 등을 추가할 수 있다.

---

## 6. 말풍선·자막 자동 생성

AI 설명은 세 가지 길이로 분리한다.

1. **말풍선**: 한 문장 핵심 설명
2. **자막**: 1~2문장 요약
3. **음성**: 맥락을 포함한 상세 설명

예:

```text
말풍선:
"현재 상태부터 확인합니다."

자막:
"push 오류를 해결하기 전에 현재 branch와 변경 파일을 확인하세요."

음성:
"push가 실패했다고 바로 force push를 사용하면 안 됩니다. 먼저 git status로 현재 branch와 수정된 파일이 있는지 확인합니다."
```

## 7. 영상 생성 파이프라인

### Phase A — 브라우저 Replay

```text
Replay Event Log
↓
Scene Timeline
↓
Git Graph / Terminal / AI Bubble 재현
↓
속도 조절 / Pause / Step
```

### Phase B — 영상 출력

```text
Scene Timeline
+ 자막
+ TTS 음성
+ UI Frame
↓
Video Renderer
↓
WebM / MP4
```

최종 영상 출력은 서버 렌더링 또는 별도 렌더 워커에서 처리하는 구조가 안정적이다.

## 8. 사용자가 직접 수정할 수 있는 항목

영상 생성 전 사용자가 다음을 수정할 수 있도록 한다.

- 교육 목표
- 대상 수준
- 영상 길이
- 재생 속도
- 포함/제외할 Step
- 말풍선 문장
- 자막
- 음성 설명
- 자격증 연결 항목
- 개인정보/저장소 정보 공개 범위

## 9. 보안·개인정보

실제 터미널 히스토리에서 다음 정보는 영상 생성 전에 자동 마스킹한다.

- API Key
- Access Token
- 이메일
- 사내 저장소 URL
- 사용자 홈 경로
- 개인정보
- 소스코드 원문 중 민감정보

예:

```text
https://github.com/private-org/secret-project
↓
https://github.com/[ORG]/[REPOSITORY]
```

원문 영상 녹화보다 구조화된 이벤트 기반 Replay를 기본으로 하는 이유도 이 마스킹을 안정적으로 적용하기 위해서다.

## 10. GitHub 자격증 학습과 연결

교육영상은 단순 콘텐츠 출력으로 끝내지 않는다.

예:

```text
push 오류 교육영상
↓
GitHub Foundations
├─ Git basics
├─ repositories
└─ collaboration
```

영상 시청 후 바로 `직접 따라하기 훈련`으로 연결한다.

```text
영상 시청
→ 직접 재현
→ 자동 채점
→ 숙련도 갱신
→ 자격증 준비도 반영
```

이 구조를 통해 영상 제작 기능이 실제 학습 데이터와 연결된다.

## 11. 모두의창업 MVP 범위

현재 제출 전에는 기능 범위를 과도하게 넓히지 않는다.

### 오늘/제출 MVP에 보여줄 것

- 교육 목표 입력 UI Mock 또는 Demo
- 성공 세션 1개 선택
- AI가 만든 Scene 목록
- 말풍선 자동 표시
- Replay 속도 조절
- 자막 표시
- 음성은 데모용 1개 장면 또는 후속 기능 표시

### 제출 이후 Phase 2

- 실제 TTS 음성 자동 생성
- 전체 세션 영상 렌더링
- WebM/MP4 다운로드
- 자동 썸네일
- 자격증별 교육영상 자동 생성
- 팀 교육영상 공유
- 영상 → 훈련 퀘스트 자동 변환

## 12. 모두의창업 차별화 메시지

### Q3-1에 활용 가능한 문장

> AI가 단순히 정답을 제공하는 데 그치지 않고, 사용자의 실제 성공 작업 히스토리를 교육 목표에 맞는 시뮬레이션·말풍선·음성 설명으로 자동 재구성하여 다시 학습하고 직접 재현할 수 있는 개인 맞춤 교육콘텐츠로 전환합니다.

### Q4-1에 활용 가능한 문장

> 초기에는 이벤트 기반 Replay와 직접 따라하기 훈련을 검증하고, 이후 AI가 학습 목표와 사용자 수준을 바탕으로 장면·자막·음성 설명을 자동 구성하여 성공 작업을 교육영상으로 생성하는 기능으로 확장합니다.

---

## 13. 사업적 의미

이 기능이 추가되면 서비스는 다음 세 가지를 하나의 데이터로 연결한다.

```text
실제 업무
→ 문제 해결
→ 경험 저장
→ 교육영상 자동 생성
→ Replay
→ 직접 훈련
→ 자격증 준비도 측정
```

즉, **실제 업무 로그를 개인 맞춤 교육콘텐츠로 자동 변환하는 Learning from Work 구조**가 된다.

장기적으로는 개인뿐 아니라 기업·대학·부트캠프에서 우수한 문제 해결 세션을 표준 교육자료로 전환하는 B2B 기능으로 확장할 수 있다.

## 결론

AI 교육영상 자동 제작은 차별성이 큰 기능이지만, 현재 모두의창업 제출 MVP에서는 `AI Scene 기획 + Replay + 말풍선 + 자막`까지를 보여주고 음성합성·MP4 렌더링은 Phase 2로 명확히 분리하는 것이 일정과 실행 가능성 측면에서 적절하다.
